# DOMAIN_HUNTER
This is how I know called "cybersquatting", well if you know, you'd probably need my program.
### How it works
You type in the TLD, and how many domains to knock, and if the domain is found, it will not show it, or show `[CLAIMED]` depending on the checkbox's value.
### Why my program?
It works fast enough and doesn't overload the DNS server. It's easy to use; easy to setup; easy to read the results. And the interface is so fucking simple that i'm not describing it here
### Why even run?
You see, there's only:
- 26 single-letter domains
- 676 double-letter domains
- 17576 triple-letter domain
- 456976 quad-letter domain
- and 11881376 penta-letter domain
The Internet has ~8 billion users, which means if you claim a 4-letter domain, you're going to attend in a group of only 0.000057% of the Internet. Isn't this great?
